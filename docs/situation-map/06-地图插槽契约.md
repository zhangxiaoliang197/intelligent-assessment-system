# 06 · 地图插槽契约

> **本文档面向地图功能同事**。定义态势图前端为地图组件预留的容器、props、事件、共享状态与数据源约定。
> 同事按此契约把「现有地图生成逻辑」封装为 Vue 组件挂入插槽；态势图框架负责同源数据注入与联动。

## 1. 设计原则

1. **同源数据**：地图与图表消费同一份「统一态势数据集」（ADR-13）。框架通过 props 注入，地图组件**不应**绕过框架自行请求业务数据（开发阶段可临时直连 DB 调试，见 §6）。
2. **最深耦合**：容器 + props + 事件 + 共享状态（Pinia），支持图表 ↔ 地图联动（ADR-04）。
3. **不破坏现有基建**：复用 Leaflet + leaflet-draw + gcoord + 外部瓦片（`/geowebcache`、`/tiles`）+ 地图配置接口 `/api/admin/config/map/active`。建议基于现有 [GeoMap.vue](../../frontend/src/components/GeoMap.vue) 扩展（Q-05）。
4. **职责分界**：框架管「数据/布局/联动/导出」；同事管「地图渲染/生成逻辑/绘制交互」。

## 2. 容器与挂入点

框架提供容器组件 `SituationMapSlot.vue`，内部暴露一个**命名插槽** `#map`，同事组件挂入：

```vue
<!-- 框架: SituationMapSlot.vue (简化) -->
<template>
  <div class="situation-map-slot">
    <div class="situation-map-header">
      <span>{{ title }}</span>
      <slot name="map-tools" />   <!-- 可选: 同事自定义工具按钮 -->
    </div>
    <div class="situation-map-body">
      <slot
        name="map"
        :dataset="dataset"
        :layers="layers"
        :viewport="viewport"
        :selected-region="selectedRegion"
        :time-range="timeRange"
        :filters="filters"
        :on-region-select="emitRegionSelect"
        :on-marker-click="emitMarkerClick"
        :on-layer-toggle="emitLayerToggle"
        :on-draw-end="emitDrawEnd"
        :on-viewport-change="emitViewportChange"
      >
        <!-- 默认占位: 未挂入同事组件时显示提示 -->
        <div class="map-placeholder">地图组件待接入</div>
      </slot>
    </div>
  </div>
</template>
```

同事使用方式（两种等价，任选）：

**方式 A：作用域插槽（推荐，最轻）**
```vue
<SituationMapSlot
  :dataset="store.activeDataset"
  :layers="store.mapLayers"
  :viewport="store.viewport"
  :selected-region="store.selectedRegion"
  @region-select="store.selectedRegion = $event"
  @marker-click="onMarkerClick"
  @layer-toggle="onLayerToggle"
  @draw-end="onDrawEnd"
  @viewport-change="store.viewport = $event"
>
  <template #map="ctx">
    <ColleagueMap
      :dataset="ctx.dataset"
      :layers="ctx.layers"
      :viewport="ctx.viewport"
      :selected-region="ctx.selectedRegion"
      @region-select="ctx['on-region-select']"
      @marker-click="ctx['on-marker-click']"
      @layer-toggle="ctx['on-layer-toggle']"
      @draw-end="ctx['on-draw-end']"
      @viewport-change="ctx['on-viewport-change']"
    />
  </template>
</SituationMapSlot>
```

**方式 B：直接挂载（同事组件自己读 Pinia，更解耦但需遵守 store 契约）**
```vue
<SituationMapSlot>
  <template #map>
    <ColleagueMap />   <!-- 内部 useSituationStore() 读数据, emit 写回 -->
  </template>
</SituationMapSlot>
```

> 方式 B 依赖同事组件直接读写 `situationStore`（见 §5 共享状态契约）。

## 3. Props 契约（框架 → 同事组件）

### 3.1 dataset（统一态势数据集）
```ts
interface SituationDataset {
  datasetId: string
  source: 'knowledge' | 'indicator' | 'evaluation' | 'admin' | 'external'
  summary: string
  // 地理要素（与现有 GeoMap.vue 同形, WGS84 经纬度）
  points: GeoPoint[]      // { name, lng, lat, raw, value?, meta? }
  routes: GeoRoute[]      // { name, points: [{lng,lat}] }
  areas: GeoArea[]        // { name, points: [{lng,lat}] }
  // 指标/时序（图表与地图共用, 用于染色/气泡）
  metrics?: Record<string, number | { value: number; unit?: string }>
  timeseries?: Array<{ t: string; values: Record<string, number> }>
}
```

> `GeoPoint/GeoRoute/GeoArea` 复用 `@/utils/geoParser`、`@/utils/geoAnnotation` 现有类型，保证与 [GeoMap.vue](../../frontend/src/components/GeoMap.vue) 兼容。

### 3.2 layers（态势业务图层）
```ts
interface MapLayer {
  layerId: string
  points?: GeoPoint[]
  routes?: GeoRoute[]
  areas?: GeoArea[]
  layerConfig: {
    color?: string
    opacity?: number
    weight?: number
    fillOpacity?: number
    visible?: boolean
  }
}
```
对应 SSE `map_layer` 事件（见 [04-接口契约.md](./04-接口契约.md) §3.1）。

### 3.3 viewport
```ts
interface Viewport { center: [number, number]; zoom: number }   // [lat, lng], GCJ02
```
框架根据 dataset 点位自动算初始 viewport（可复用 GeoMap.vue 的 `fitViewport` 逻辑）。

### 3.4 联动状态
- `selectedRegion: string | null`：当前选中区域名/id（地图选区 → 图表过滤）。
- `timeRange: [number, number] | null`：时间范围。
- `filters: Record<string, any>`：其他筛选。

## 4. 事件契约（同事组件 → 框架）

| 事件 | payload | 触发时机 | 框架响应 |
|------|---------|----------|----------|
| `region-select` | `{ regionId: string, name: string, geometry?: GeoJSON }` | 用户在地图选区/点击区域 | 写入 `store.selectedRegion` → 图表按区域过滤重渲 |
| `marker-click` | `{ point: GeoPoint, layerId?: string }` | 点击标记 | 高亮对应图表数据点 |
| `layer-toggle` | `{ layerId: string, visible: boolean }` | 切换图层显隐 | 更新 `store.mapLayers[i].layerConfig.visible` |
| `draw-end` | `{ type: 'polygon'|'polyline'|'circle'|'marker', geojson: GeoJSON, name?: string }` | leaflet-draw 绘制完成 | 存入手绘图层，可参与筛选/导出 |
| `viewport-change` | `Viewport` | 地图平移/缩放结束 | 写入 `store.viewport`（用于导出复现） |

## 5. 共享状态契约（Pinia: situationStore）

若同事组件采用「方式 B」直接读写 store，须遵守：

- **只读字段**（同事不写）：`datasets`、`mapLayers` 的数据部分、`charts`、`narrative`。
- **可写字段**（同事通过 action 写）：`selectedRegion`、`selectedTimeRange`、`filters`、`viewport`。
- 写入必须经 action（如 `setSelectedRegion(payload)`），便于触发图表联动 watcher。

store 定义见 [05-前端设计.md](./05-前端设计.md) §3。

## 6. 数据源与开发阶段约定

- **生产**：地图组件**只消费 props 注入的 dataset/layers**，不自行发业务请求。
- **开发阶段**：同事可临时直连 admin-service 数据库（或 `/api/admin/*`）调试自有生成逻辑，但**不得**在合入代码里保留直连（遵循「禁硬编码 URL」「跨服务经环境变量」规范）。
- **底图瓦片**：复用 `/geowebcache`、`/tiles`（9090 服务）与 `/api/admin/config/map/active` 配置，与 GeoMap.vue 一致；同事组件可调用框架提供的 `loadMapConfig()` 工具或自行加载。

## 7. 坐标系约定

- dataset/layers 中的经纬度统一为 **WGS84**。
- 渲染前由 gcoord 转 **GCJ02**（与 GeoMap.vue `transformCoord` 一致）。
- `draw-end` 回传的 geojson 用 WGS84（框架统一转）。

## 8. 导出兼容

- 态势图导出（html2canvas）会截取地图区域。同事组件须保证：
  - 瓦片 `<img>` 设置 `crossOrigin="anonymous"`（Leaflet 默认支持，需瓦片服务配 CORS）。
  - 导出前可响应框架发出的 `before-export` 事件，临时隐藏绘制控件/动画。
- 若导出地图出现跨域空白，回退方案：导出时临时切换为静态图层或截图占位。
