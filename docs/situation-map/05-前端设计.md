# 05 · 前端设计

> 前端基建已具备：Vue3 + TS + Vite、Element Plus、Pinia、Tailwind、**ECharts + vue-echarts**、**Leaflet + leaflet-draw**、marked + dompurify、lucide-vue-next。
> 本功能复用上述依赖，原则上不新增重型库（导出新增 `html2canvas` + `jspdf`）。

## 2. 页面结构（SituationMap.vue）

布局**不固死**——采用可拼装的栅格区域，按生成阶段动态显示：

```
┌──────────────────────────────────────────────────────────┐
│ 顶部栏: 标题 | 来源(qa/indicator/evaluation/直接) | 导出 分享 刷新 历史 │
├──────────────────────────────────────────────────────────┤
│ 提问栏: [输入框 ....................................] [生成] │
│        (跳转进入时自动填充 query，可编辑)                    │
├──────────────────────────────┬───────────────────────────┤
│ 图表区 (ECharts, 注册表驱动)   │ 地图插槽区                │
│  ┌──────┐ ┌──────┐ ┌──────┐  │ <SituationMapSlot>        │
│  │chart1│ │chart2│ │chart3│  │  (同事组件挂入, 同源数据)   │
│  └──────┘ └──────┘ └──────┘  │  与图表联动(选中区域→高亮) │
│  ... 流式逐个冒出              │                           │
├──────────────────────────────┴───────────────────────────┤
│ 文本区: 态势介绍(markdown)  +  逐图说明(按 chartId 锚定)    │
└──────────────────────────────────────────────────────────┘
```

布局策略：
- 默认左图表右地图；窄屏自动堆叠（Tailwind 响应式）。
- 图表数量多时图表区可滚动/网格自适应。
- 「界面框架不要定死」：图表/地图/文本三区为独立组件块，可拖拽重排（v1.x），v1 先固定三区 + 响应式。

## 3. 状态管理（Pinia: situationStore）

```ts
// stores/situation.ts
interface SituationState {
  reportId: string | null
  status: 'idle' | 'generating' | 'ready' | 'partial' | 'failed'
  query: string
  source: 'manual' | 'qa' | 'indicator' | 'evaluation'

  // 统一态势数据集（图表与地图同源, ADR-13）
  datasets: Dataset[]
  activeDatasetId: string | null

  // 图表
  charts: ChartSpec[]              // {chartId, type, title, option, explanation}

  // 地图
  mapLayers: MapLayer[]            // 与 06 章插槽 props 对齐

  // 文本
  narrative: { intro: string; explanations: Array<{chartId:string;text:string}> }

  // 联动共享状态（图表 ↔ 地图）
  selectedRegion: string | null    // 地图选区 → 图表过滤
  selectedTimeRange: [number, number] | null
  filters: Record<string, any>

  // SSE
  eventSource: EventSource | null
}
```

核心 actions：`initFromDraft(draftId)` / `generate(query)` / `subscribeSSE(reportId)` / `applyEvent(event)` / `refresh()` / `exportPDF()` / `share()`。

**所有 SSE 事件经 `applyEvent` 落到 store**，图表/地图组件响应式渲染——这就是「图表与地图同源 + 联动」的落点。

## 4. SSE 接收器

```ts
// composables/useSituationStream.ts
const es = new EventSource(`/api/situation/stream/${reportId}`)
es.addEventListener('chart', e => situationStore.applyEvent({ type:'chart', data: JSON.parse(e.data) }))
es.addEventListener('map_layer', e => situationStore.applyEvent({ type:'map_layer', ... }))
es.addEventListener('narrative', e => situationStore.applyEvent({ type:'narrative', ... }))
es.addEventListener('done', e => { situationStore.status = JSON.parse(e.data).status; es.close() })
es.addEventListener('error', e => { /* 提示, 重连策略 */ })
```

## 5. 图表注册表（可扩展）

```ts
// components/charts/registry.ts
export interface ChartDefinition {
  type: string
  name: string                  // 中文名
  component: any                // ECharts 包装组件
  buildOption?: (spec: ChartSpec) => any   // 可选: 对 LLM 给的 option 做后处理
}

const REGISTRY = new Map<string, ChartDefinition>()

export function registerChart(def: ChartDefinition) { REGISTRY.set(def.type, def) }
export function getChart(type: string) { return REGISTRY.get(type) }

// 起步集（v1）
registerChart({ type:'bar', name:'柱状图', component: VueECharts })
registerChart({ type:'line', name:'折线图', component: VueECharts })
registerChart({ type:'pie', name:'饼图', component: VueECharts })
registerChart({ type:'radar', name:'雷达图', component: VueECharts })
registerChart({ type:'gauge', name:'仪表盘', component: VueECharts })
registerChart({ type:'scatter', name:'散点图', component: VueECharts })
registerChart({ type:'heatmap', name:'热力图', component: VueECharts })
registerChart({ type:'relation', name:'关系图', component: VueECharts })
registerChart({ type:'sankey', name:'桑基图', component: VueECharts })
registerChart({ type:'map', name:'地图染色', component: VueECharts })
```

渲染：
```vue
<component :is="getChart(chart.type)?.component || VueECharts" :option="chart.option" />
```

新增图表类型只需 `registerChart`，不改框架——满足「框架不定死、灵活多变」。

## 7. 文本区

- 态势介绍：`marked.parse(intro)` + `dompurify.sanitize` 渲染。
- 逐图说明：按 `chartId` 与图表锚定，点击说明→滚动到对应图表并高亮。
- 文本在图表之后渲染（响应 `narrative` 事件），符合 ADR-08。

## 8. 跨功能跳转接收

```ts
// SituationMap.vue onMounted
const draftId = route.query.draftId as string
if (draftId) {
  const draft = await api.get(`/situation/draft/${draftId}`)
  situationStore.initFromDraft(draft.data)   // 填充 query/source/context
  if (draft.data.context.autoGenerate) situationStore.generate(draft.data.context.query)
}
```

## 9. 导出（前端截图，ADR-12）

新增依赖：`html2canvas` + `jspdf`。

```ts
async function exportPDF() {
  const node = document.querySelector('.situation-capture-root') as HTMLElement
  const canvas = await html2canvas(node, { scale: 2, useCORS: true, backgroundColor:'#fff' })
  const pdf = new jsPDF('p', 'mm', 'a4')
  // 分页处理 ...
  pdf.save(`${report.title}.pdf`)
}
```

注意：
- Leaflet 地图导出需 `preferCSSPageSize` + 瓦片 `crossOrigin` 配置，否则截图跨域瓦片空白。
- 导出前可临时隐藏交互控件（绘制工具栏等）。

## 10. 历史与分享页

- `SituationList.vue`：调 `GET /api/situation/reports`，表格展示，点击→`/situation?reportId=xxx` 加载详情。
- `SituationShare.vue`：路由 `/situation/share/:token`，调 `GET /api/situation/share/:token`，只读渲染（无编辑/导出按钮可酌情保留导出）。
