# 08 · 部署配置清单

> 新增 situation-service 涉及的配置改动清单。**规则（来自 project_rules）：新增 API 路径必须同步 vite.config.ts + nginx.conf；新增跨服务调用必须同步 start-docker-run.sh 的 -e 环境变量。**

## 1. 前端 vite 代理（[vite.config.ts](../../frontend/vite.config.ts)）

在 `server.proxy` 新增：

```ts
'/api/situation': {
  target: 'http://localhost:10257',
  changeOrigin: true,
  rewrite: (path) => path.replace(/^\/api/, '')
},
```

> SSE 路径 `/api/situation/stream/:id` 同样命中此规则（Vite 开发代理默认支持 SSE）。

## 2. nginx 反向代理（docker/nginx.conf）

新增 location：

```nginx
# 态势图 REST
location /api/situation/ {
    proxy_pass http://assessment-situation:10257/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-User-Id $http_x_user_id;
    proxy_set_header X-Team-Ids $http_x_team_ids;
}

# 态势图 SSE（关键: 关闭缓冲 + 长超时）
location ~ ^/api/situation/stream/ {
    proxy_pass http://assessment-situation:10257;
    proxy_http_version 1.1;
    proxy_set_header Connection '';
    proxy_buffering off;          # ★ SSE 必须
    proxy_cache off;
    proxy_read_timeout 3600s;
    proxy_send_timeout 3600s;
    chunked_transfer_encoding on;
}
```

## 3. 跨服务环境变量（start-docker-run.sh）

新增容器 `assessment-situation`，需注入：

| 环境变量 | 值（Docker） | 默认值（本地） | 说明 |
|----------|--------------|----------------|------|
| `ADMIN_SERVICE_URL` | `http://assessment-admin:10258` | `http://localhost:10258` | LLM 配置/地图配置/持久化 CRUD |
| `QA_SERVICE_URL` | `http://assessment-qa:10253` | `http://localhost:10253` | 知识检索/评估结果 |
| `KNOWLEDGE_SERVICE_URL` | `http://assessment-knowledge:10252` | `http://localhost:10252` | 知识库直接检索（可选） |
| `INDICATOR_SERVICE_URL` | `http://assessment-indicator:10254` | `http://localhost:10254` | 指标数据 |
| `EXTERNAL_DS_URL` | （按数据源） | 空 | 外部实时数据源（预留） |
| `LLM_MAX_TOKENS` | `24000` | `24000` | 与 ontology-service 一致 |
| `LOG_ENV` | `prod` | `dev` | 日志环境 |
| `LOG_LEVEL` | `INFO` | `INFO` |  |
| `LOG_DIR` | `/app/logs` | `./logs` |  |

> **不配置 `ONTOLOGY_SERVICE_URL`**，体现态势图独立于本体（ADR-01/05）。
> **不配置 `QDRANT_URL`**，态势图不直连向量库。

在 `start-docker-run.sh` 新增容器启动段：

```bash
docker run -d --name assessment-situation \
  --network assessment-net \
  -p 10257:10257 \
  -e ADMIN_SERVICE_URL=http://assessment-admin:10258 \
  -e QA_SERVICE_URL=http://assessment-qa:10253 \
  -e KNOWLEDGE_SERVICE_URL=http://assessment-knowledge:10252 \
  -e INDICATOR_SERVICE_URL=http://assessment-indicator:10254 \
  -e LLM_MAX_TOKENS=24000 \
  -e LOG_ENV=prod -e LOG_LEVEL=INFO -e LOG_DIR=/app/logs \
  assessment-situation:1.0.0
```

## 4. Dockerfile（python/situation-service/Dockerfile）

参照现有 Python 服务 Dockerfile 模式：

```dockerfile
FROM python:3.11-slim
WORKDIR /app
# 系统依赖（与 knowledge-service 不同：situation-service 不需要 sentence-transformers）
COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY . .
EXPOSE 10257
CMD ["python", "-u", "main.py"]
```

requirements.txt 起步（按需增减）：

```txt
fastapi
uvicorn[standard]
pydantic
python-dotenv
# urllib 为标准库, 无需安装
```

> 不依赖 langchain / sentence-transformers（轻量服务）。

## 5. docker-compose.yml

新增 service：

```yaml
assessment-situation:
  build: ./python/situation-service
  container_name: assessment-situation
  ports:
    - "10257:10257"
  environment:
    - ADMIN_SERVICE_URL=http://assessment-admin:10258
    - QA_SERVICE_URL=http://assessment-qa:10253
    - KNOWLEDGE_SERVICE_URL=http://assessment-knowledge:10252
    - INDICATOR_SERVICE_URL=http://assessment-indicator:10254
    - LLM_MAX_TOKENS=24000
    - LOG_ENV=prod
    - LOG_LEVEL=INFO
    - LOG_DIR=/app/logs
  depends_on:
    - assessment-admin
  networks:
    - assessment-net
```

## 6. start.ps1（本地启动）

在 Python 服务列表新增 situation（端口 10257）。当前 5 个 Python 服务变 6 个：

```powershell
# 服务列表: knowledge(10252), qa(10253), indicator(10254), evaluation(10255), ontology(10256), situation(10257)
```

启动方式与现有 Python 服务一致：

```powershell
Start-Process python -ArgumentList "-u main.py" -WorkingDirectory "$r\python\situation-service" -WindowStyle Hidden
```

> start.ps1 必须 UTF-8 with BOM（PowerShell 5 解析中文注释），遵循现有约束。

## 7. init-mysql.sql（admin-service 表）

追加（见 [07-数据模型与存储.md](./07-数据模型与存储.md) §2）：

```sql
CREATE TABLE IF NOT EXISTS situation_report (
  id            VARCHAR(40)  PRIMARY KEY,
  title         VARCHAR(200) NOT NULL,
  query         TEXT,
  source        VARCHAR(20),
  user_id       VARCHAR(64),
  team_ids      VARCHAR(255),
  status        VARCHAR(20)  NOT NULL DEFAULT 'generating',
  snapshot_json LONGTEXT,
  share_token   VARCHAR(64),
  created_at    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  updated_at    DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  INDEX idx_user (user_id),
  INDEX idx_team (team_ids),
  INDEX idx_share (share_token)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='态势图产物';
```
