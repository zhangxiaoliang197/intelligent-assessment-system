## 本体与实例
“本体图”展示类、属性、继承关系和逻辑限制；“实例图”展示装备、编组、任务、事件等具体对象。顶部搜索框可按名称查找资源，选中节点后可查看其属性和邻接关系。

## 编辑数据
选择节点后使用编辑操作修改名称、类型和属性。通过节点连接操作建立关系，也可在文件面板导入完整本体。双击节点可展开或折叠属性。撤销与重做支持恢复画布编辑操作。资源标识与命名空间前缀用于明确区分同名资源。

## 布局与聚类
“布局”提供自上而下、从左到右、分层、力导向、密集图和径向布局。可调节节点间距、动画与自动布局。“聚类”提供标签传播、鲁汶和 K 均值算法，支持按结构和社群层级折叠。左下角可缩放、适应画布，右下角缩略图可快速定位。

## 本体推理
点击顶部执行按钮或底部“本体推理”，使用 Konclude 引擎进行完整 OWL 2 DL 分类与一致性检查。推导事实显示在独立推导图中，不会自动变成业务断言。点击推理状态可打开报告，查看推导结果、错误、警告、矛盾解释与修复建议。修改事实后应重新执行推理。

## 约束验证
侧栏“约束验证”用于加载和管理 SHACL 规则。内置规则检查本体名称与文档完整性，装备协同推演另有装备状态、任务进度和评估溯源规则。推理时可同时进行约束验证。报告中区分违规、警告和提示，支持定位相关节点。

## 图谱查询
侧栏“图谱查询”提供 SPARQL 查询编辑器。可执行查询和更新语句，当前命名空间前缀会自动注入；代码中的标准关键词、变量、资源标识和文件格式名称保持原样。直接断言位于 `urn:vg:data`，推导事实位于 `urn:vg:inferred`。

```sparql
SELECT ?装备 WHERE {
  GRAPH <urn:vg:inferred> {
    ?装备 a <https://example.org/qinglan/schema#ReadyPlatform> .
  }
}
```

## 导入导出
“文件”用于导入本地 RDF、本体文本和关联数据文件。“导出”可生成本体文本、结构化关联数据、四元组或多图数据集。原生画布还支持导出位图、矢量图与打印。导入的类、公理、匿名节点和属性类型会保留其完整语义。

## 保存与版本
顶部“保存本体”、画布中的“保存”和 Ctrl/Cmd+S 都将数据保存到智能评估系统，同时保留命名空间、画布位置与多图数据集。“版本记录”可以将历史快照载入草稿，检查后保存为新版本。出现并发修改提示时，请重新载入并合并修改。

## 装备协同推演
内置样例包含 8 台装备、2 个协作小组、3 个协作单元和 3 项任务。四个回合依次为初始编组、状态变化、协同处理和推演复盘。点击回合可查看装备状态、任务进度和评估依据随时间的变化。

“就绪装备”由装备状态自动分类，“具备就绪装备的编组”由至少编配一台就绪装备推导。回合 0 应推导出 8 台就绪装备，回合 1 为 6 台。切换回合会清理旧推导，保存前不会覆盖当前持久化版本。

## 智能体与工作流
侧栏保留原项目的智能体连接、变更溯源和语义工作流功能。智能体连接通过浏览器工具接口操作当前图谱，变更记录可查看差异并恢复。外部工作流目录和模型服务需要在设置中自行配置，默认不自动加载远程内容。

本工作台基于 Ontosphere 1.8.1 与 Reactodia，遵循 Apache-2.0 许可。原项目源码及许可随本项目保留。
