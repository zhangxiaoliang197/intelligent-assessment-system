## 取数剧本
- need: mode=aggregate, question=按日期统计威胁指数与当日最高威胁等级的时间序列
- need: mode=aggregate, question=按日期统计打击事件与侦察发现事件次数用于解释同期威胁变化

## 区块剧本
kpi(威胁现状) → chart(威胁水平时间趋势) → timeline(关键时点) → chart(同期事件对比) → text(结论)
- 时间轴区块与折线图共用同一份按日数据，只标记确实存在的突变时点，不要凭空生成刻度
- 同期事件图表放在趋势图之后，用于解释拐点而非替代趋势

## 呈现偏好
- 连续时间趋势必须用折线图，不要用柱状图表达趋势；离散时段的对比才用柱状图
- 突变时点在时间轴区块中以文字标注，不要在折线图上堆叠大量标注导致遮挡
- 时间范围筛选通过事件总线联动趋势图、时间轴与事件图表
- 每个图表给出中文标题与一句话结论；结论区放页面底部

## 叙事要点
- 先给当前威胁水平，再给演化方向与变化速度，最后用同期事件解释突变时点
- 必须回答的问题：威胁是持续升高、回落还是震荡、在哪个时段发生突变、变化能否被同期事件解释
- 相关性不等同因果：解释关系时必须保留「同期」「可能相关」等限定语，不得宣称已证实因果
- 缺少记录的时段必须显式说明数据缺失，不得当作零威胁处理
