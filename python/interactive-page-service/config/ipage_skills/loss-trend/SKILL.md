## 取数剧本
- need: mode=aggregate, question=按日期与阵营统计当日战损数量与累计战损数量
- need: mode=aggregate, question=按战损类型、程度与阵营统计损耗构成
- need: mode=detail, geo=points, question=战损事件的位置、发生时间、类型与原因明细

## 区块剧本
kpi(损耗概览) → chart(双方战损趋势) → chart(战损类型构成) → map(战损事件点位) → text(结论)
- 双方趋势放在同一折线图中作为两个系列，便于直接比较而非并排放两张图
- 战损事件点位地图按阵营与程度符号化，事件时刻纳入时间轴

## 呈现偏好
- 时间趋势用折线图；类型与程度构成分类较少时用饼图，否则改用条形图
- 双方对比固定「蓝方在前、红方在后」，保证多次生成的系列次序一致
- 阵营色由运行时自动映射，不要在图表中写死颜色；事件点位密集区域需要聚合并标注数量
- 每个图表给出中文标题与一句话结论；结论区放页面底部

## 叙事要点
- 先给双方战损总量与差距，再给时间趋势与拐点，最后落到类型构成与空间分布
- 必须回答的问题：双方损耗差距在扩大还是收窄、拐点出现在哪个时段、损耗主要来自哪些类型
- 用同期事件解释拐点时保留「同期」「可能相关」等限定语，不得把相关性表述为因果
- 「无战损」的时段与类别必须如实呈现，不得只展示损失较重的一方
