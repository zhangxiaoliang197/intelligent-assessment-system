# 知识库服务 - 本地环境配置指南

知识库服务（v2.0）基于 **Qdrant** 向量数据库 + **BGE** 嵌入模型实现语义检索，以下依赖需手动下载。

---

## 1. Qdrant 向量数据库

**版本**：v1.18.3（Windows 二进制）

**下载地址**：
```
https://github.com/qdrant/qdrant/releases/download/v1.18.3/qdrant-x86_64-pc-windows-msvc.zip
```

**安装步骤**：

1. 创建目录 `qdrant/`，解压 zip 到该目录
2. 在 `qdrant/` 下创建 `config.yaml`：

```yaml
log_level: INFO

storage:
  storage_path: ./storage
  snapshots_path: ./snapshots
  on_disk_payload: true

performance:
  max_search_threads: 0

service:
  host: 0.0.0.0
  http_port: 6333
  grpc_port: 6334
  enable_cors: true
  enable_static_content: true
  static_content_dir: ./static

cluster:
  enabled: false
```

3. 下载 Web Dashboard（可选）：

```
https://github.com/qdrant/qdrant-web-ui/releases/latest/download/dist-qdrant.zip
```

解压到 `qdrant/static/`，启动后访问 `http://localhost:6333/dashboard`

4. 启动：

```powershell
cd D:\qdrant
.\qdrant.exe
```

## 2. BGE 嵌入模型

**模型**：`BAAI/bge-small-zh-v1.5`（512 维，~100MB）

**方式一：huggingface 镜像（推荐）**

```powershell
pip install huggingface_hub
python -c "
from huggingface_hub import snapshot_download
snapshot_download(
    'BAAI/bge-small-zh-v1.5',
    local_dir='models/bge-small-zh-v1.5',
    local_dir_use_symlinks=False,
    endpoint='https://hf-mirror.com',
    resume_download=True
)
"
```

**方式二：ModelScope 国内源**

```powershell
pip install modelscope
python -c "
from modelscope import snapshot_download
import shutil, os

# 下载到临时目录
tmp = snapshot_download('BAAI/bge-small-zh-v1.5', cache_dir='./_tmp_models')

# 找到包含 1_Pooling 的实际模型目录，复制到 models/bge-small-zh-v1.5/
# 然后删除 _tmp_models
"
```

**目录结构要求**：

```
models/
  bge-small-zh-v1.5/
    1_Pooling/
      config.json
    config.json
    model.safetensors
    tokenizer.json
    tokenizer_config.json
    vocab.txt
    ...
```
