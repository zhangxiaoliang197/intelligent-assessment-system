# map_place_marker — 地图标点

## 技能描述
在地图上标注离散的地理位置点。每个点位可以附带名称，多个点位用不同颜色区分。

## 触发条件
- 用户要求标注某个具体地点、位置、城市、基地等
- 用户使用关键词：标点、标记、标注位置、地图标注、标记点、点位
- 用户询问"XX在哪里"并期望地图展示
- SQL/数据查询结果中包含经纬度数据列

## 输出格式
在回答末尾，使用 `map_annotations` 代码块输出标注数据，JSON 格式。仅输出用户要求或数据中确实存在的点位，不要编造。

```map_annotations
{
  "markers": [
    {
      "name": "点位名称（简短明确，如'北京'、'指挥所'、'雷达站A'）",
      "lng": 116.4074,
      "lat": 39.9042
    }
  ]
}
```

### 字段说明
| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| markers | array | 是 | 标注点列表，数量不限 |
| markers[].name | string | 是 | 点位名称，2-8个中文字符为佳 |
| markers[].lng | number | 是 | 经度，范围 [-180, 180] |
| markers[].lat | number | 是 | 纬度，范围 [-90, 90] |

### 约束
- 同名点位坐标必须一致
- 坐标精度不低于小数点后4位
- 不编造坐标，若不确定具体坐标，在正文中说明并省略标注块

## 示例

### 用户输入
> 标注北京、上海、广州三个城市的位置

### AI 回复正文
```
北京、上海、广州三大城市的地理位置如下：

【北京】位于华北平原北部，东经116.40°，北纬39.90°
【上海】位于长江入海口，东经121.47°，北纬31.23°
【广州】位于珠江三角洲，东经113.26°，北纬23.13°

以上三座城市已在地图上标注。
```

```map_annotations
{
  "markers": [
    { "name": "北京", "lng": 116.4074, "lat": 39.9042 },
    { "name": "上海", "lng": 121.4737, "lat": 31.2304 },
    { "name": "广州", "lng": 113.2644, "lat": 23.1291 }
  ]
}
```

## 颜色规则
前端会根据坐标自动分配颜色，同一坐标的点位颜色相同，不同坐标颜色不同。
