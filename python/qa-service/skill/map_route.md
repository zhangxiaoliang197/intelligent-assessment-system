# map_draw_route — 地图连线（路线/路径/航线）

## 技能描述
在地图上用折线连接一系列坐标点，形成路线或路径。适用于标注攻击路线、行军路径、航线、迁移轨迹等。

## 触发条件
- 用户要求绘制路线、路径、航线、轨迹、行进路线
- 用户使用关键词：路线、路径、航线、连线、轨迹、行军、进攻路线、撤退路线
- 用户描述从A到B经过C的路径

## 输出格式
在回答末尾，使用 `map_annotations` 代码块输出标注数据，JSON 格式。每条路线必须包含至少2个途经节点。

```map_annotations
{
  "routes": [
    {
      "name": "路线名称（简短明确，如'红军进攻路线'、'补给线A'）",
      "points": [
        { "lng": 116.32, "lat": 39.89 },
        { "lng": 116.45, "lat": 39.92 },
        { "lng": 116.51, "lat": 40.05 }
      ]
    }
  ]
}
```

### 字段说明
| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| routes | array | 是 | 路线列表，可包含多条路线 |
| routes[].name | string | 是 | 路线名称，2-10个中文字符 |
| routes[].points | array | 是 | 途经节点列表，至少2个点 |
| routes[].points[].lng | number | 是 | 经度，范围 [-180, 180] |
| routes[].points[].lat | number | 是 | 纬度，范围 [-90, 90] |

### 约束
- 每条路线至少2个节点，按实际行进顺序排列
- 节点之间以直线连接，前端渲染为虚线折线
- 多条路线用不同颜色区分
- 不编造坐标

## 示例

### 用户输入
> 画出红军从A基地经B集结点到C目标的进攻路线

### AI 回复正文
```
红军进攻路线如下：

起点A基地（东经115.20°，北纬38.50°）
→ 经B集结点（东经116.10°，北纬39.20°）
→ 达到C目标（东经117.05°，北纬40.10°）

全程约280公里，途经平原和丘陵地带。
```

```map_annotations
{
  "routes": [
    {
      "name": "红军进攻路线",
      "points": [
        { "lng": 115.20, "lat": 38.50 },
        { "lng": 116.10, "lat": 39.20 },
        { "lng": 117.05, "lat": 40.10 }
      ]
    }
  ]
}
```

### 多条路线示例
```map_annotations
{
  "routes": [
    {
      "name": "红军主攻方向",
      "points": [
        { "lng": 115.20, "lat": 38.50 },
        { "lng": 116.10, "lat": 39.20 }
      ]
    },
    {
      "name": "蓝军增援路线",
      "points": [
        { "lng": 118.50, "lat": 39.00 },
        { "lng": 117.30, "lat": 38.80 }
      ]
    }
  ]
}
```

## 渲染规则
前端以彩色虚线折线渲染，每条路线一个颜色，节点处显示小圆点。
