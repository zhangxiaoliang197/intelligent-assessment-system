# map_draw_area — 地图范围（区域/多边形）

## 技能描述
在地图上绘制闭合多边形区域，用于标注行政区域、作战范围、管控区域、影响范围等。

**重要**：不要简化为矩形！应尽量贴近真实轮廓，模拟自然地理边界的曲折形态。即使无法精确到每个细节，也要用8-20个顶点描摹出大致轮廓。

## 触发条件
- 用户要求绘制范围、区域、边界、轮廓、圈定范围
- 用户使用关键词：范围、区域、边界、轮廓、圈出、画出XX范围、管辖区
- 用户询问"XX覆盖哪些区域"期望地图展示

## 输出格式
在回答末尾，使用 `map_annotations` 代码块输出标注数据，JSON 格式。

区域有两种形状可选：

**多边形（shape: "polygon"，默认）**：至少3个顶点，推荐8-25个顶点以呈现精细轮廓。
```map_annotations
{
  "areas": [
    {
      "name": "区域名称（简短明确，如'北京市行政范围'、'红方防空识别区'）",
      "shape": "polygon",
      "points": [
        { "lng": 115.42, "lat": 39.44 },
        { "lng": 116.25, "lat": 39.50 },
        { "lng": 117.30, "lat": 40.10 },
        { "lng": 116.85, "lat": 40.82 },
        { "lng": 116.20, "lat": 41.06 },
        { "lng": 115.68, "lat": 40.62 },
        { "lng": 115.45, "lat": 40.10 }
      ]
    }
  ]
}
```

**圆形（shape: "circle"）**：用于辐射范围、覆盖半径、影响圈等。
```map_annotations
{
  "areas": [
    {
      "name": "圆形区域名称",
      "shape": "circle",
      "center": { "lng": 119.00, "lat": 38.50 },
      "radiusKm": 50
    }
  ]
}
```

### 字段说明
| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| areas | array | 是 | 区域列表，可包含多个区域 |
| areas[].name | string | 是 | 区域名称，2-10个中文字符 |
| areas[].shape | string | 否 | `"polygon"`（默认）或 `"circle"` |
| areas[].points | array | polygon必需 | 边界顶点列表，至少3个点形成闭合多边形，推荐8-25个 |
| areas[].points[].lng | number | 是 | 经度，范围 [-180, 180] |
| areas[].points[].lat | number | 是 | 纬度，范围 [-90, 90] |
| areas[].center | object | circle必需 | 圆心坐标 |
| areas[].center.lng | number | 是 | 圆心经度 |
| areas[].center.lat | number | 是 | 圆心纬度 |
| areas[].radiusKm | number | circle必需 | 圆半径，单位公里，范围 (0, 5000] |

### 约束
- shape 为 "circle" 时使用 center+radiusKm，忽略 points
- shape 为 "polygon" 或省略时使用 points，至少3个顶点
- **多边形顶点尽量用8-25个描绘真实轮廓，禁止简单矩形框！**
- 圆形适用于：雷达覆盖、火力范围、电磁干扰半径、影响范围等
- 顶点按顺时针或逆时针依次排列，前端按你给定的顺序连线
- 不需要手动闭合（重复首点），前端自动处理
- 区域范围尽可能准确，不编造
- 多个区域可以混合 polygon 和 circle

### 轮廓精细化策略
按区域类型选择顶点数量：

| 区域类型 | 推荐顶点数 | 示例 |
|----------|-----------|------|
| 城市行政边界 | 10-20 | 北京、上海 |
| 省级行政区域 | 15-25 | 河北、山东 |
| 沿海省份边界 | 12-20 | 海岸线部分增加顶点密度 |
| 作战区域/防空识别区 | 8-15 | 沿山脉、河流等自然地物 |
| 圆形影响范围 | 8-12 | 近似圆形，顶点均匀分布 |
| 扇形/弧形区域 | 8-15 | 弧形段多顶点，直边少顶点 |
| 岛屿群 | 按岛屿数×6 | 每个岛屿独立为一个 area |

**轮廓模拟方法**：
1. 基于你对地理的认知，逐个区县/地市描摹边界走向
2. 沿海区域沿海岸线增加顶点，内陆边界沿省界走向
3. 凸出/凹陷处各设一个顶点，不要跳过明显的拐弯
4. 如果确实不了解详细轮廓，用近似多边形+正文注明"近似范围"

## 示例

### 示例1：不规则多边形（8个顶点）
```map_annotations
{
  "areas": [
    {
      "name": "红方防空识别区",
      "points": [
        { "lng": 118.00, "lat": 38.00 },
        { "lng": 119.20, "lat": 37.80 },
        { "lng": 120.50, "lat": 37.50 },
        { "lng": 121.00, "lat": 38.20 },
        { "lng": 121.00, "lat": 39.00 },
        { "lng": 119.50, "lat": 40.00 },
        { "lng": 118.20, "lat": 39.60 },
        { "lng": 117.80, "lat": 39.20 }
      ]
    }
  ]
}
```

### 示例2：圆形范围（雷达覆盖）
```map_annotations
{

    {
      "name": "雷达覆盖范围",
      "shape": "circle",
      "center": { "lng": 119.00, "lat": 38.50 },
      "radiusKm": 150
    }
  ]
}
```

### 示例3：多个区域混合（多边形+圆形）
```map_annotations

  "areas": [

      "name": "红方东部控制区",
      "points": [
        { "lng": 119.00, "lat": 38.00 },
        { "lng": 120.20, "lat": 37.80 },
        { "lng": 121.00, "lat": 38.40 },
        { "lng": 121.00, "lat": 39.20 },

    },
    {
      "name": "蓝方南部防线",
      "points": [
        { "lng": 117.00, "lat": 36.00 },

        { "lng": 117.50, "lat": 37.00 },
        { "lng": 117.00, "lat": 36.50 }
      ]
    }
  ]
}
```

## 渲染规则
- 多边形：半透明填充色（fillOpacity: 0.12），边框线宽2px，不同区域不同颜色
- 圆形：半透明填充，空心圆环边框，圆心处有标记点
- 多边形的顶点按你给定的顺序连线，前端不会做凸包排序

## 组合使用
可以与其他地图技能在同一回答中组合使用。例如标点 + 多边形管控区 + 圆形雷达覆盖：

```map_annotations
{
  "markers": [
    { "name": "指挥所", "lng": 116.00, "lat": 40.00 }
  ],
  "areas": [
    {
      "name": "警戒区域",
      "shape": "polygon",
      "points": [
        { "lng": 115.00, "lat": 39.50 },
        { "lng": 116.30, "lat": 39.80 },
        { "lng": 116.50, "lat": 40.80 },
        { "lng": 115.50, "lat": 40.60 },
        { "lng": 115.00, "lat": 40.10 }
      ]
    },
    {
      "name": "雷达覆盖范围",
      "shape": "circle",
      "center": { "lng": 118.00, "lat": 40.00 },
      "radiusKm": 80
    }
  ]
}
```

注意：一个 `map_annotations` 块中 `markers`、`routes`、`areas` 可以同时存在，也可以只包含其中一种。
