# 数据质量综合评估

从完整性、唯一性、有效性和一致性角度综合检查目标数据集质量。

## 基本信息

- Skill ID：`data-quality-assessment`
- 分类：数据质量

## 触发词

- 数据质量
- 质量评估
- 数据健康度
- 质量检查
- 脏数据

## 推荐问题

- 综合评估这张表的数据质量
- 检查数据完整性、唯一性和有效性

## 执行步骤

### 1. 执行质量概览

围绕空值、重复、非法状态和异常范围生成可执行的质量统计。

- 步骤 ID：`quality`
- 数据集关键词：`数据`、`质量`、`明细`、`主数据`、`业务记录`
- 操作：`dataset_query`

## 输出要求

按完整性、唯一性、有效性和一致性分别给出证据、问题等级及优先修复建议。
