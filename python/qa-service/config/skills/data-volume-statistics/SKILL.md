# 数据量统计

统计目标数据集的总记录数，并可按用户指定维度汇总各分组数量。

## 基本信息

- Skill ID：`data-volume-statistics`
- 分类：统计分析

## 触发词

- 数据量
- 记录数
- 总条数
- 多少条数据
- 数量统计

## 推荐问题

- 统计这张表一共有多少条数据
- 按主要分类统计各组记录数

## 执行步骤

### 1. 统计记录数量

查询目标数据集总记录数；问题包含分组维度时同时统计各组数量。

- 步骤 ID：`volume`
- 数据集关键词：`数据`、`记录`、`明细`、`业务表`、`统计`
- 操作：`dataset_query`

## 输出要求

给出总记录数、分组数量和占比，并说明使用的数据集和统计口径。
