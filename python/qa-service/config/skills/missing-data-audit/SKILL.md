# 缺失值检查

检查目标数据集关键字段的空值和缺失情况，定位缺失最严重的字段或分组。

## 基本信息

- Skill ID：`missing-data-audit`
- 分类：数据质量

## 触发词

- 缺失值
- 空值检查
- 字段为空
- 数据缺失
- null统计

## 推荐问题

- 检查这张表哪些字段存在缺失值
- 统计关键字段的空值数量和缺失率

## 执行步骤

### 1. 检查字段缺失

统计用户点名关键字段的空值数量；未点名时优先检查核心业务字段。

- 步骤 ID：`missing`
- 数据集关键词：`数据`、`明细`、`主数据`、`记录`、`质量`
- 操作：`dataset_query`

## 输出要求

按字段列出总记录数、缺失数量、缺失率和风险等级，避免把合法的零值误判为缺失。
