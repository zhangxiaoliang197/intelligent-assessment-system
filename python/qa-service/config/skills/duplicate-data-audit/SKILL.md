# 重复数据检查

基于用户指定主键或业务组合键检查重复记录，汇总重复组数和受影响记录数。

## 基本信息

- Skill ID：`duplicate-data-audit`
- 分类：数据质量

## 触发词

- 重复数据
- 重复记录
- 查重
- 唯一性检查
- 重复值

## 推荐问题

- 按业务主键检查重复数据
- 统计这张表有多少重复记录

## 执行步骤

### 1. 检查记录重复

按用户指定的主键或业务字段组合分组，查找计数大于一的重复记录。

- 步骤 ID：`duplicate`
- 数据集关键词：`数据`、`明细`、`主数据`、`记录`、`唯一键`
- 操作：`dataset_query`

## 输出要求

输出判重字段、重复组数、受影响记录数和典型重复样例；未明确判重字段时说明采用的候选字段。
