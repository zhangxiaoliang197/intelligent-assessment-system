# 描述性统计分析

对数值字段计算数量、最小值、最大值、平均值和汇总值等基础统计指标。

## 基本信息

- Skill ID：`descriptive-statistics`
- 分类：统计分析

## 触发词

- 描述性统计
- 基础统计
- 平均值
- 最大最小
- 统计摘要

## 推荐问题

- 对主要数值字段做描述性统计
- 统计指定指标的平均值、最大值和最小值

## 执行步骤

### 1. 计算统计摘要

依据用户指定字段计算记录数、最小值、最大值、平均值和总量。

- 步骤 ID：`summary`
- 数据集关键词：`指标`、`数值`、`金额`、`数量`、`统计`
- 操作：`dataset_query`

## 输出要求

按字段给出有效记录数、最小值、最大值、平均值和总量，并明确空值处理口径。
