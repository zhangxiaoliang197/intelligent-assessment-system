# 异常值检测

依据用户给出的规则、阈值或统计范围筛查异常记录并汇总异常分布。

## 基本信息

- Skill ID：`anomaly-detection-analysis`
- 分类：数据质量

## 触发词

- 异常值
- 异常数据
- 离群值
- 超出范围
- 异常检测

## 推荐问题

- 检查指定指标中明显异常的记录
- 按阈值筛查超出正常范围的数据

## 执行步骤

### 1. 筛查异常记录

优先使用用户给定阈值；未给定时基于字段业务范围和分布筛查异常候选。

- 步骤 ID：`anomaly`
- 数据集关键词：`指标`、`数值`、`监测`、`记录`、`异常`
- 操作：`dataset_query`

## 输出要求

输出异常判定规则、异常数量、占比、典型记录和分布；统计规则推断必须标注为候选而非事实。
